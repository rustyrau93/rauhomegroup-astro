The Difference

Option A — 5 shades

Minimal. Adds depth (dark navy) + warmth (soft gold) + breathing room (ice). Body text stays navy. Tight and clean. Start here if you want zero risk.

Option B — 6 shades

Same as A + Slate for body text. Headlines pop more when body text is a softer navy. Easier on the eyes for long-form pages. Better if we're building content-heavy pages.
